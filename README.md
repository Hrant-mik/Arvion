# 🩺 Emergency Medical Card System

**Hackathon Project: Accessible Emergency Medical Information Platform with Face Recognition & QR Code Integration**

## 🔍 Նկարագիր

Այս նախագիծը նպատակ ունի ստեղծել անվտանգ, արագ և հեշտ հասանելի հարթակ՝ առողջապահական կարիքների համար, որը կօգնի բժիշկներին արտակարգ իրավիճակներում արագորեն ստանալ հիվանդի կարևոր տվյալները։ Օգտատերերը ստեղծում են պրոֆիլ, լրացնում բժշկական տվյալներ և ստանում QR կոդով անվտանգ քարտ, որը կարելի է ցուցադրել կամ կարդալ դեմքի ճանաչմամբ։

## 🚀 Տեխնոլոգիաներ

- **Backend**: Python + Django
  - Ներկառուցված Admin, ORM, Authentication համակարգ
- **Database**: 
  - PostgreSQL (հզոր տարբերակ), SQLite (հարմար hackathon-ի համար)
- **Դեմքի ճանաչում**:
  - `face_recognition` գրադարան (dlib-ի հիման վրա)
  - կամ `OpenCV` Haar Cascades / DNN
- **Frontend**:
  - HTML, CSS, JavaScript
  - Bootstrap (արագ UI ստեղծման համար)
- **QR Կոդեր**:
  - `qrcode` գրադարան՝ QR կոդի գեներացման համար
- **PDF Գեներացում**:
  - `reportlab` կամ `xhtml2pdf`՝ թվային քարտի ստեղծման համար

## 🧭 Կայքի կառուցվածք

- **Գլխավոր էջ**՝ ներկայացնում է նպատակը, առավելությունները, և CTA ("Ստեղծիր Քո Քարտը")
- **Մուտք/Գրանցում**՝ բաժանում `Պացիենտի` և `Բժշկի` միջերեսների
- **Պացիենտի Dashboard**:
  - Անձնական տվյալներ, բժշկական տեղեկություն, պրոֆիլի խմբագրում
  - QR կոդի գեներացում և PDF քարտի ներբեռնում
- **Բժշկի Dashboard**:
  - Որոնում՝ անունով, հիվանդությամբ, կամ դեմքով (Face Recognition)
  - Պացիենտի պրոֆիլի դիտում (միայն հաստատված բժիշկների համար)

## 🔐 Անվտանգություն

- Django-ի անվտանգության գործիքներ՝ CSRF, hashed գաղտնաբառեր, SQL injection պաշտպանություն
- QR հղումները պարունակում են անվտանգ token-ներ
- Մուտքը սահմանափակ է՝ ըստ օգտատիրոջ կարգավիճակի

- ✅ Բժշկական տվյալների կենտրոնացված պահպանում
